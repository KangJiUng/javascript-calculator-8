# javascript-calculator-precourse (문자열 덧셈 계산기)

## 기능 요구 사항

- 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.

- 기본 구분자(쉼표, 콜론) 외에 커스텀 구분자를 지정할 수 있다. 커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.

- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션은 종료되어야 한다.

## 구현 고려 사항

- 빈 문자열이나 숫자만 입력될 수도 있다. (결과는 0)

- 커스텀 구분자의 지정은 문자열 앞 부분에 -> 최대 한 번만 가능하다고 가정한다.

- 양수에는 실수도 포함되므로 마침표(.)가 커스텀 구분자로 지정되지 않는 이상 실수로 판단하여 연산한다.

- 구분자는 혼합으로 사용될 수 있다.

- 커스텀 구분자로 숫자 및 공백은 사용할 수 없다고 가정한다.

- 구분자 사이 또는 앞에 문자열이 없으면 0으로 판단한다.

- 구분자만 입력된 경우 및 커스텀 구분자 지정만 되는 경우에는 0으로 판단한다.(빈 문자열은 0으로 반환함에 따라 일관성)

## 사용자가 잘못된 값을 입력한 경우

- 커스텀 구분자를 지정한 위치가 잘못된 경우

- 커스텀 구분자 지정을 두 번 이상한 경우

- 커스텀 구분자 지정에 "//"와 "\n" 중 하나가 사용되지 않은 경우

- 커스텀 구분자 "//"와 "\n" 사이에 아무런 문자열이 없는 경우

- 구본자(기본, 커스텀)로 지정되지 않은 구분자가 사용된 경우

- 양수가 아닌 숫자가 포함된 경우

- ...

## 구현할 기능 목록

- [x] 쉼표(,) 또는 콜론(:)로 숫자를 구분하고 숫자를 더한다.

- [x] 문자열 앞부분의 "//"와 "\n"로 커스텀 구분자가 있으면 이것으로 숫자를 구분하고 숫자를 더한다. (쉼표(,) 또는 콜론(:)도 구분자로 사용)

- [x] 마침표(.)가 포함되어있다면 커스텀 구분자로 마침표(.) 지정 여부에 따라 정수 또는 실수로 판단하여 연산한다. (굳이 따로 처리하지 않아도 됨)

- [x] 잘못된 값 입력에 대해 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션을 종료시킨다.
